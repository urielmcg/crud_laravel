Qué es Laravel

Laravel es un framework de código abierto para PHP que sigue el patrón Modelo–Vista–Controlador (MVC). Separa la lógica de negocio, la presentación y el flujo de la aplicación para que el código sea ordenado, reutilizable y fácil de mantener.

Arquitectura MVC

Los modelos representan los datos, las vistas presentan la información al usuario y los controladores coordinan las peticiones. Esta separación facilita el trabajo en equipo y las pruebas.

Eloquent ORM

Eloquent permite interactuar con la base de datos mediante clases de PHP en lugar de escribir SQL manualmente. Cada tabla tiene su modelo y las relaciones (uno a muchos, muchos a muchos) se expresan con métodos claros.

Blade

Blade es el motor de plantillas de Laravel. Permite crear diseños reutilizables, componentes y estructuras de control con una sintaxis sencilla que se compila a PHP puro para un rendimiento óptimo.

Artisan

Artisan es la interfaz de línea de comandos incluida en cada proyecto. Genera controladores, modelos y migraciones, ejecuta el servidor local, aplica migraciones y automatiza tareas repetitivas del desarrollo diario.

Por qué elegir Laravel

Estas seis capacidades explican por qué Laravel es uno de los frameworks PHP más utilizados en proyectos profesionales y académicos.

Enrutamiento expresivo

Define rutas claras para cada URL de la aplicación, con soporte para parámetros, grupos, middleware y nombres de ruta que simplifican el mantenimiento.

Eloquent ORM

Migraciones, fábricas de datos, relaciones y consultas encadenables que reducen el SQL repetitivo y mantienen la base de datos bajo control de versiones.

Blade

Plantillas con herencia de diseños, componentes reutilizables y directivas intuitivas para construir interfaces consistentes con menos código.

Artisan

Generadores de código, servidor de desarrollo, colas, programador de tareas y comandos personalizados para automatizar el flujo de trabajo.

Seguridad integrada

Protección contra inyección SQL, falsificación de peticiones (CSRF), scripts entre sitios (XSS), cifrado y gestión de autenticación y autorización listas para usar.

Ecosistema completo

Forge para aprovisionar servidores, Vapor para despliegue sin servidor en AWS y Nova para paneles de administración. Todo el ciclo de vida del proyecto queda cubierto.

Instalación paso a paso

Guía mínima para crear un proyecto Laravel 12 en un equipo local. Verifique primero los requisitos y luego ejecute los comandos en orden.

Requisitos previos

  • PHP >= 8.2 con las extensiones requeridas por Laravel
  • Composer (gestor de dependencias de PHP)
  • Node.js + npm (para compilar recursos con Vite)
  • Base de datos: SQLite (la opción más simple) o MySQL
  • Git (para control de versiones)

Pasos de instalación

  1. Paso 1. Crear un proyecto nuevo con Composer:

    composer create-project laravel/laravel ejemplo-app

  2. Paso 2. Entrar a la carpeta del proyecto:

    cd ejemplo-app

  3. Paso 3. Instalar dependencias de interfaz y compilar recursos con Vite:

    npm install && npm run dev

  4. Paso 4. Iniciar el servidor local de desarrollo:

    php artisan serve

    Luego abra en el navegador la dirección indicada (normalmente http://127.0.0.1:8000).

Alternativas opcionales

Herd: entorno local para macOS y Windows que incluye PHP, Composer y Nginx con un solo instalador, ideal para comenzar sin configurar servidores manualmente.

Laravel Cloud: plataforma oficial para desplegar aplicaciones Laravel sin administrar infraestructura, útil cuando el proyecto debe quedar disponible en internet para la exposición.
